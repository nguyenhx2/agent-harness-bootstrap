---
description: Refresh the context docs from the current state of the repository.
---

Refresh `docs/context/` so it describes the repository as it is now, not as it
was when someone last remembered to write it down.

- Re-read the dependency manifests and update the stack notes.
- Re-read the module owners and update the ownership table.
- Leave anything a human wrote by hand alone unless it is now false.

This command is deliberately a description of a job rather than a procedure:
the order does not matter and the work is not a sequence. There is no numbered
list here, and the viewer must show this prose instead of an empty steps panel.
